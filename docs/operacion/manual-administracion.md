# Manual de administración

## Propósito

Este manual guía a quien administra usuarios, roles y establecimientos. La administración no debe crear contraseñas para otras personas: el sistema envía una invitación de un solo uso para que cada funcionario/a cree la propia.

## Preparar el establecimiento

1. Ingrese a **Administración → Establecimientos**.
2. Cree o revise el establecimiento, sus etapas y su estado activo.
3. Confirme que las etapas reflejen el flujo institucional antes de crear casos reales.
4. Mantenga los nombres de etapas, categorías y protocolos acordados por el establecimiento.

## Crear, asignar e invitar a una persona

1. Vaya a **Administración → Usuarios** y seleccione **Nuevo usuario**.
2. Ingrese nombre completo, correo institucional, uno o más roles y el establecimiento correspondiente.
3. Revise cuidadosamente el correo y el rol antes de confirmar.
4. Seleccione **Crear, asignar e invitar**.

En una sola acción se crea la cuenta, se asignan los roles, se incorpora la membresía activa al establecimiento y se envía la invitación. La persona abre el enlace recibido y define su contraseña. Nunca solicite ni almacene esa contraseña.

## Cuando una persona no aparece para asignar un caso

Revise, en este orden:

1. La cuenta debe estar activa.
2. Debe tener membresía activa en el mismo establecimiento del caso.
3. Debe tener un rol con la capacidad institucional que corresponda.
4. Si se creó recién, recargue la vista y confirme que la invitación o activación no haya sido revocada.

La asignación de un caso se limita al establecimiento para evitar que alguien vea expedientes ajenos.

## Gestión de accesos

- Use **Roles y permisos** para revisar capacidades antes de otorgar un rol.
- Desactive una cuenta cuando la persona deja de participar; no reutilice cuentas ni credenciales.
- Reenvíe una invitación solo después de verificar la dirección institucional.
- Revocar sesiones fuerza un nuevo inicio de sesión en dispositivos previos.
- Revise **Auditoría** ante cambios relevantes de acceso o administración.

## Cierre administrativo periódico

Mensualmente, revise cuentas inactivas, funciones que cambiaron, membresías por establecimiento y roles con privilegios altos. Documente quién efectuó la revisión y las acciones tomadas.
