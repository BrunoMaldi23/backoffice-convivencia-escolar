# Operación y uso de la plataforma

Esta carpeta es la referencia vigente para preparar, capacitar y aprobar el uso de la plataforma. Los contratos de `docs/api` son técnicos; los informes de fase son antecedentes históricos.

| Documento | Destinatario | Propósito |
| --- | --- | --- |
| [Manual de administración](manual-administracion.md) | Administración del sistema | Usuarios, roles, establecimientos, membresías e invitaciones. |
| [Manual de convivencia](manual-convivencia.md) | Encargado/a de convivencia y equipo autorizado | Gestión cotidiana de expedientes y evidencias. |
| [Matriz UAT](matriz-uat.md) | Equipo de validación | Pruebas de aceptación antes de salida institucional. |
| [Preparación operativa](preparacion-operativa.md) | Dirección, TI y administración | Decisiones, responsables y controles previos a datos reales. |
| [Despliegue de staging Vercel/Render](despliegue-staging-vercel-render.md) | TI y desarrollo | Configuración, variables y comprobaciones para el entorno de prueba. |

## Regla de uso

Use cuentas de prueba y datos ficticios durante la capacitación y UAT. No copie contraseñas, enlaces de evidencia ni datos de estudiantes en capturas, correos o documentos de capacitación.
